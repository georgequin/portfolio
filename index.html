// about me

Building products that scale — and securing them

I'm a Senior Software Engineer with 8+ years of experience delivering production-grade apps across fintech, govtech, and consumer platforms. I've shipped 17+ apps to over a million users, working across Flutter, native Android (Java & Kotlin), and Spring-based backends.

Having built the application and API layers of financial and identity systems from the inside, I now focus that knowledge on offensive security — testing the same web and API surfaces I used to ship. Engineers who understand a system's internals make sharper attackers of it, and I bring that dual perspective to payment gateways, authentication flows, and integration channels.

  • Application & API security testing (web, REST, auth flows)
  • Burp Suite Pro · JWT & authentication attacks · OWASP Top 10
  • Deep engineering background — Flutter, Native Android, Spring
  • OSWE certified · GXPN in progress
